## دیپلوی Railway

1. این ریپو را Deploy کنید
2. Volume روی `/data`
3. Public Domain فعال
4. متغیرها **اختیاری** هستند. توکن و ادمین ربات را از داخل داشبورد (بخش ربات تلگرام) وارد کن؛ در Volume ذخیره می‌شود.

   در صورت نیاز:
   - `PANEL_PATH` — مسیر مخفی پنل (وگرنه خودکار ساخته می‌شود)
   - `TELEGRAM_BOT_TOKEN` / `TELEGRAM_ADMIN_IDS` — فقط اگر نخواهی از UI ست کنی

5. در Railway: **Enable Outbound IPv6** (اختیاری ولی توصیه‌شده)

ورود: `https://DOMAIN/{PANEL_PATH}/login`

## ربات فروش — راهنمای ادمین

1. توکن و آیدی ادمین را در پنل یا env ست کنید
2. در ربات: **تنظیم کارت بانکی** → `شماره‌کارت|نام`
3. **مدیریت محصولات** → افزودن با فرمت:
   `نام|قیمت|حجم‌GB|روز|پروتکل`
   مثال: `یک‌ماهه|150000|50|30|vless-ws`
4. کاربران از **خرید سرویس** سفارش می‌دهند و رسید می‌فرستند
5. ادمین از **سفارش‌های در انتظار** تأیید می‌کند → کانفیگ خودکار ساخته می‌شود
